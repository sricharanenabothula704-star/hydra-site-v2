    Trust

    Security & limits

    What HYDRA enforces, what it only suggests, and what you still have to check yourself.

    Use it only where you are authorized

    Test only systems you own or have written authorization to assess. Agent instructions require a scope review. The CLI and loop runner enforce the allowlist for their guarded commands.

    Scope enforcement has edges

    Standalone helper scripts may not enforce the allowlist. Prompt instructions are not enforcement. Read a script before you run it, and confirm scope before any traffic is sent.

    Your data and providers

    Findings are stored locally by default. That is not a guarantee nothing leaves your machine. Cloud model providers receive the prompts you send. Configured tools may contact their targets or other services. Review provider terms, privacy settings and scripts.

    Results are candidates

    The Verifier is heuristic. Oracle checks may miss bugs or produce false positives. There is no benchmark yet for precision or recall. Human reproduction is required before any report or action.

    !

    The coordination server is not hardened

    The optional coordination server binds to 0.0.0.0:5000 with no authentication and serves submitted findings over HTTP. Do not run it as shipped. Keep it on localhost or put it behind your own authentication and network controls.

    The build agent also has shell and edit permissions in the shipped config. Review the permissions in the opencode.jsonc.template before you run it on anything you care about.

    Reporting a vulnerability in HYDRA

    Please report security issues in HYDRA itself privately, not in a public issue. Follow the repo's SECURITY.md. Do not include working exploits for third-party systems in reports.

    Responsible use

    HYDRA is for authorized security testing, defensive work and learning. Read the disclaimer and the bug bounty program's rules before you test anything. This site has no live connection to any target: the console and globe on the homepage are simulations.
