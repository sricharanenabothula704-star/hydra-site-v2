    The seven heads

    Every agent, explained properly

    Each agent is a markdown definition file: mission, mindset, decision frameworks and output contracts. Tap a node in the core to read its summary, then scroll for the full deep-dive.

    HUNTER primary · temp 0.2

    the exploitation lead

    What it does. Runs the full reconnaissance-to-exploitation pipeline: subdomain enumeration, CDN filtering so scans hit real origins, port discovery, vulnerability templates and directory fuzzing. Then it probes what it found in continuous cycles.

    Why. Most hunters fail at asset discovery, not exploitation. So Hunter treats recon as 80% of the job and carries a decision table: a 403 means try a bypass, a WAF block means use the vendor table, silence after N cycles means change layers.

    • Runs httpx, naabu, nuclei and ffuf pipelines (in scope only)
    • Saves every lead instantly with a hash
    • Refuses to proceed without confirmed scope
    • Stops at minimal proof on high-impact finds
    • Tags everything UNVERIFIED for the Verifier

    VERIFIER primary · temp 0.1

    the quality gate

    What it does. Takes every finding and tries to destroy it: baseline request vs exploit request, three replays, response diffing and false-positive signature checks. Then an honest CVSS score and a confidence percentage.

    Why. Bounty platforms track researcher accuracy. Three sloppy reports can end an account. The Verifier's charter: if you can't reproduce it confidently, reject it.

    • ≥80% → VERIFIED, moves forward
    • 50–79% → PARTIAL, flagged for human review
    • <50% → REJECTED, with a written reason
    • Every rejection notes its false-positive signature
    • Dry spells raise standards, not lower them

    REPORTER primary · temp 0.1

    the submission writer

    What it does. Turns verified findings into platform-ready reports: a title under 120 characters, a summary that states severity plainly, working curl PoCs with truncated proof output, CWE mapping, a CVSS vector and impact in the business's own terms.

    Why. A triager reads your report between meetings. The best report turns their job into a five-minute confirmation.

    • Show, don't claim
    • Honest severities beat inflated ones
    • Report fast, but never skip verification for speed

    PLAN primary · temp 0.3

    the strategist

    What it does. Before anyone fires a packet, Plan researches the target on the open web: tech stack, program scope, known CVEs, acquisitions. Then it builds a prioritized attack plan.

    Why. Priorities are set up front. P0 authentication flows first, P3 header trivia last, with success criteria and pivot conditions (for example, no findings after N cycles means switch approach).

    AUDITOR primary · temp 0.1

    the code reviewer

    What it does. When you have source instead of a URL, Auditor reads it like an attacker. It maps trust boundaries first, sweeps dangerous sinks second, then goes deep on authorization logic, session handling, crypto misuse and mass assignment.

    Why. A dangerous function with no route to it is not a bug. Every finding must show file, line, a reachable path and a minimal proof.

    RECON subagent · temp 0.1

    the surface mapper

    What it does. The fast path. Exhausts free passive sources (certificate transparency, archives, passive DNS) before touching the target. Resolves and deduplicates, tags CDN-shielded hosts, and harvests JS bundles and source-map leads.

    Contract. Every result carries evidence of origin, high-value targets ranked by attack value, and an explicit safe to port scan / do not port scan split. It stops when two consecutive phases add less than 5% new assets.

    DEBUG primary · temp 0.4

    the self-improvement engine

    What it does. Sees across all agents. When something breaks downstream (bad reports, weak verification, sloppy hunting), Debug diagnoses upstream.

    Why. Every logged mistake must end with a concrete prevention rule. Memory entries without prevention rules are just diaries. When things go wrong, Debug de-escalates, fixes, documents and prevents.
