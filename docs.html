    Quick start

    Install, connect, scope, run.

    Four steps. Nothing scans until you point HYDRA at a target you are authorized to test.

    Clone and set up

    git clone https://github.com/sricharanenabothula704-star/hydra.git && cd hydra && bash setup.sh --handle YOUR_HANDLE --email you@example.com. An existing OpenCode config is backed up, and replaced only after you approve.

    Connect a model provider

    Launch OpenCode, run /connect to authenticate, then /models to select one. Model-backed workflows send prompts to that provider. A local Ollama setup keeps prompts on your machine.

    Write your scope allowlist

    Add exact authorized domains to ~/.config/opencode/SCOPE_ALLOWLIST.txt. The CLI and loop runner deny targets outside it.

    Run guarded commands

    hydra doctor for preflight, hydra scan URL for a scoped HTTP-header audit, hydra hunt URL to invoke the configured hunter.

    Commands

    hydra doctor                          # preflight checks
hydra scan https://app.example.test   # scoped HTTP-header audit (must be in allowlist)
hydra hunt https://app.example.test   # invoke the configured OpenCode hunter
hydra skills route --task "jwt auth"  # rank playbooks for a task
./scripts/hydra_loop.sh targets.txt 40  # continuous loop, scope-checked per target
./scripts/run_meta.sh                 # run ID, timestamp, provider, tool versions
./scripts/hydra_models.sh             # credential check for 23 env-key providers

    Verify, then report

    Feed leads to /verify. Survivors go to /report, which drafts a platform-style writeup with reproducible PoCs. Reproduce every claim yourself before you submit.

    Optional: browser validation (Playwright MCP)

    From the repo, run /playwright-setup. The agent checks prerequisites, explains changes, and asks before downloading packages or editing config. The MCP stays disabled until you approve enabling it. After enabling, use /browser-check https://your-authorized-host.

    Playwright inspects rendered pages and client-side behavior. It does not bypass bot detection and does not enforce HYDRA's allowlist. If you hit a CAPTCHA, bot challenge, rate limit or access denial, stop. Do not try to evade it.
